# Especies de Fauna Silvestre del Libro Rojo (SERFOR, 2018)

Lista de 528 especies de fauna silvestre amenazada analizadas en el
Libro Rojo de la Fauna Silvestre Amenazada del Perú.

## Usage

``` r
libro_rojo_especies
```

## Format

Un tibble con 528 filas y 7 variables:

- libro_rojo_id:

  Número correlativo.

- libro_rojo_categoria:

  Nombre de la categoría de amenaza.

- libro_rojo_codigo:

  Código de categoría ordenado (CR, EN, VU, NT, DD).

- grupo_taxonomico:

  Grupo taxonómico (Anfibios, Aves, Invertebrados, Mamíferos, Reptiles).

- scientific_name_raw:

  Nombre científico tal como figura en la publicación.

- sinonimo:

  Sinónimo o nombre adicional.

- scientific_name:

  Nombre científico normalizado.

## Source

Servicio Nacional Forestal y de Fauna Silvestre (SERFOR, 2018).
